# CORA_PROJECT

Sistema de gestión de una biblioteca.

## Tecnologías
- PHP
- MySQL
- MySQL Workbench
- XAMPP
- HTML
- CSS
- JavaScript

## Estructura
- app: lógica del proyecto y arquitectura MVC.
- public: archivos públicos CSS, JavaScript e imágenes.
- database: scripts de base de datos.
- docs: documentación.
- tests: pruebas del sistema.
